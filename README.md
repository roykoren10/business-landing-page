# Business Landing Page

דף פיץ׳ בעברית עבור חברה המספקת פתרונות בינה מלאכותית מותאמים לעסקים קטנים ובינוניים.

## צפייה מקומית

פתחו את `index.html` בדפדפן. העמוד בנוי ב־HTML ו־CSS בלבד, כולל תמיכה מלאה ב־RTL והתאמה למסכים שונים ולהדפסה.

## תוכן

- הפיץ׳ לחברה
- הצגת המייסדים
- גרסת מעלית קצרה
- משפטים מובילים אפשריים
